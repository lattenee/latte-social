# latte-social

Closed-loop social content pipeline for the Vietnam market: keyword/trend → AI script/caption → video & image generation → multi-channel scheduling/publishing → analytics feedback.

## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Uses the five canonical labels: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` at repo root + `docs/adr/` for decisions. See `docs/agents/domain.md`.
